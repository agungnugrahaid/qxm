Run these CLI commands in your RouterOS terminal to enable scheduling and remote syslogging: 
# 1. Create the system scheduler triggers (metrics every 5m, firmware daily)
/system scheduler add name=qoe-push-metrics interval=5m on-event=qoe-push-metrics
/system scheduler add name=qoe-push-firmware interval=1d on-event=qoe-push-firmware

# 2. Configure remote syslog forwarding to Loki
/system logging action add name=qoe-remote target=remote remote={{ syslog_ip }} remote-port={{ syslog_port }}
/system logging add action=qoe-remote topics=info
/system logging add action=qoe-remote topics=warning
/system logging add action=qoe-remote topics=error
/system logging add action=qoe-remote topics=critical
