Manage customers
Controls which routers "Deploy critical only" on the router list targets -- for phasing a large rollout.
Requires a certificate already assigned to the router's api-ssl service -- run the script below on the router's terminal first (see routeros/README.md for background). 
/certificate add name=api-ssl-cert common-name=REPLACE_ME key-usage=tls-server,key-cert-sign,crl-sign
/certificate sign api-ssl-cert
/ip service set api-ssl certificate=api-ssl-cert
Paste into the router's terminal (Winbox/SSH), then check "Use api-ssl" above and set the management port to 8729. Once confirmed working, also disable the plaintext api service on the router (/ip service disable api) -- it's a real brute-force target if reachable from the internet.
