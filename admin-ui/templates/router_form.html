Controls targeting for "Deploy critical only" rollout phase.
Requires a certificate already assigned to the router's api-ssl service. Run the script below in RouterOS terminal first: 
/certificate add name=api-ssl-cert common-name=REPLACE_ME key-usage=tls-server,key-cert-sign,crl-sign
/certificate sign api-ssl-cert
/ip service set api-ssl certificate=api-ssl-cert
Paste this setup script into your router's terminal. Then check "Use api-ssl" above and set the management port to 8729. Once confirmed working, remember to disable plaintext api (/ip service disable api).
